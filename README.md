
# AttendX-Test-Scripts

## Project Description
AttendX is a student attendance application.
This repository stores sample automated test scripts
using Git and GitHub for version control.

## Test Scripts

### 1. test_login.py
Tests valid login and invalid password scenarios.

### 2. test_attendance_marking.py
Tests successful attendance marking and invalid
student ID handling.

## Requirements
- Python 3
- Git
- Visual Studio Code

## How to Run the Tests
Run the following commands in the terminal:

python -m unittest test_login.py
python -m unittest test_attendance_marking.py

## Purpose
Git and GitHub are used to track changes, maintain
commit history, and collaborate with the QA team.
